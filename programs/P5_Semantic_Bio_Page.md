# P5 – Semantic bio page

## Aim
Create a short personal bio using meaningful HTML elements.

## Code
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Bio</title>
</head>
<body>
  <header>
    <h1>Hi, I'm a Student Developer</h1>
    <p>Learning to build useful things for the web.</p>
  </header>

  <main>
    <section>
      <h2>About Me</h2>
      <p>I am a first-year student interested in web development,
         problem solving and technology.</p>
    </section>
    <section>
      <h2>My Interests</h2>
      <ul>
        <li>Learning HTML and CSS</li>
        <li>Trying small coding projects</li>
        <li>Exploring new technology</li>
      </ul>
    </section>
  </main>

  <footer>
    <p>Contact: student@example.com</p>
  </footer>
</body>
</html>
```

## Result
The page is divided into header, main content, sections and footer instead of using generic containers everywhere.
