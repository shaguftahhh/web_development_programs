# P1 – Project folder and terminal navigation

## Aim
Create a project folder and practise moving around it from the terminal.

## Steps (macOS / Linux)
```bash
mkdir my-portfolio
cd my-portfolio
mkdir images css
touch index.html style.css
pwd
ls
cd css
cd ..
```

## What the commands do
- `mkdir` creates a folder.
- `cd` changes the current directory.
- `pwd` shows the current location.
- `ls` lists files and folders.
- `touch` creates an empty file.

## Result
A folder named `my-portfolio` is created with `images`, `css`, `index.html`, and `style.css` inside it.
